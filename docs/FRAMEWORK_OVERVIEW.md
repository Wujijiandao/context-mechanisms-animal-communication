# Framework overview

The project asks a mechanistic-identification question rather than merely whether context affects behaviour.
Its central logic is:

```text
observed context effect
    -> compatible mechanism family
    -> discriminating measurement or intervention
```

The P/T/I/H/A labels are a compact, factorisation-relative bookkeeping scaffold:

- **P — production:** context changes emitted signal structure;
- **T — transmission/sensory access:** context changes the sensory evidence available to a receiver;
- **I — current-context information integration:** current contextual information alters receiver processing or inference;
- **H — history-dependent receiver state:** prior experience alters receiver state through learning and memory;
- **A — response decision/action selection:** context changes downstream response selection, costs or payoffs.

The point is not that these are newly discovered biological stages. The point is that an observed behavioural effect may be
compatible with more than one causal location. Stronger experiments are those that reduce the compatible set through additional
measurements, cue conflicts, catch trials, sensory calibration, or orthogonal payoff manipulations.
