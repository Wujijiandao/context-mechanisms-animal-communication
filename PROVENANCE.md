# Provenance

The canonical analysis scripts in this repository were consolidated from an earlier exploratory research workflow and then rerun against retained
data extracts. Fixed numerical checks were subsequently used to guard the maintained implementation against accidental drift.

This release should therefore be cited as the maintained reproducible implementation of the analyses, but it should not be described as though every
current source file existed byte-for-byte during the earliest exploratory sessions.

The public v1.0.0 regression suite covers the fully redistributable titi 2013 extract plus data-independent simulation/SDT components. Additional
analysis scripts are included, while third-party-derived processed data without clearly verified redistribution terms are intentionally omitted from
the public repository. See `data/README.md`.
